LandscapeDesk
Private internal tool for landscaping businesses. Flask + SQLite. No public signup: access is by owner approval.
Run locally
pip install -r requirements.txt
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD='a-long-password' python app.py
Open http://127.0.0.1:5000 and sign in as the owner. The first admin is created from those two environment variables only if no admin exists yet. Nothing is hardcoded.
Deploy on Render
Upload all files to a GitHub repo, create a Web Service, and set ADMIN_EMAIL and ADMIN_PASSWORD (SECRET_KEY is generated by render.yaml). Start command: gunicorn app:app --workers 1. Keep workers at 1 (SQLite).
Important limits
Render's free plan has no persistent disk, so the SQLite file resets on redeploy/restart. For real clients, use a paid plan with a disk (set DB_PATH to the disk path) or move to Postgres.
Not implemented: login rate limiting, password reset, logo upload (logo is a URL), payments, PDF generation (use the Print / save as PDF button), email sending (none, by design), React/TypeScript.
Run python test_smoke.py for the checks listed below.
Owner workflow
Admin > Create account (demo or real), or approve access requests. Demo accounts get fictional "Sample:" leads, an expiry date, and are blocked on the server the moment they expire or are revoked.
